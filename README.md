# .github

Organization-wide defaults for [RSOcc26](https://github.com/RSOcc26).
GitHub uses these files in every repository that does not have its own copy.

| Path | Purpose |
|---|---|
| `profile/README.md` | The organization's public profile page |
| `CONTRIBUTING.md` | How we branch, commit, review and merge |
| `SECURITY.md` | How to report a vulnerability |
| `SUPPORT.md` | Where to ask questions |
| `.github/ISSUE_TEMPLATE/` | Bug report and feature request forms |
| `.github/pull_request_template.md` | The checklist every pull request starts from |
| `docs/` | CompanyCentral architecture, ADRs and RSO requirements traceability |

A repository overrides any of these by adding its own file with the same name.
